# Library Management System SQL

A database project developed for the course **CSE311**.

## Project Description

The Library Management System is a SQL-based database designed to manage books, members, authors, publishers, categories, and book loans efficiently.

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

## Main Features

- Member management
- Book management
- Author management
- Publisher management
- Category management
- Book loan and return management
- SQL queries for retrieving useful information

## Database Entities

- Member
- Book
- Author
- Publisher
- Category
- Loan
